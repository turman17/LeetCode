# LeetCode


My LeetCode solutions, written in Go.

Everything here is written by me, without AI. I'm using this repo to learn algorithms and data structures properly, so you'll see the real process: The commit history for each problem shows how the solution got better (if it got).

I try to solve and publish a new problem every day.

## Structure

Each problem has its own folder under `Go/`, named after the LeetCode number and title:

```
Go/283.MoveZeroes/main.go
```

To run one:

```
go run Go/283.MoveZeroes/main.go
```
